PORTFOLIO ABOUBAKER ADEN FARAH — HTML, CSS ET JAVASCRIPT

Fichiers :
- index.html : structure et contenu du site.
- style.css : design sombre/violet, mise en page, responsive et animations.
- script.js : projets, compétences, menu mobile, carrousel horizontal et bouton copier e-mail.
- assets/profile.jpg : photo de profil.

LANCEMENT
1. Décompresse le ZIP.
2. Ouvre le dossier dans VS Code.
3. Ouvre index.html puis clique sur Go Live si Live Server est installé. Tu peux aussi double-cliquer sur index.html pour l'ouvrir dans un navigateur. Aucun npm install n'est nécessaire.

À SAVOIR
- Les photos des projets sont chargées depuis Unsplash : une connexion Internet est nécessaire pour les afficher.
- Pour changer les projets, modifie le tableau projects dans script.js.
- Le bouton « Copier l'e-mail » utilise l'API Clipboard du navigateur ; elle fonctionne surtout avec localhost/Live Server ou HTTPS.
- Remplace les liens génériques de réseaux sociaux par tes profils personnels.

Pour expliquer au professeur : HTML structure les sections, CSS crée le design et les animations, JavaScript génère les cartes de projets et de compétences, fait défiler le carrousel, gère le menu mobile et copie l'adresse e-mail.
